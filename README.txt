FMGE Mock Test - GitHub Pages package

1. On github.com create a new repository (for example: fmge-mock).
2. Click Add file > Upload files, then drag in index.html AND the atlas folder (both). Commit.
3. Open Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. After about a minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/

Notes
- Progress (XP, history, bookmarks) is saved inside each browser on each device. It does not sync between phone and laptop.
- The atlas folder holds the question pictures (23 files). Keep it next to index.html.
